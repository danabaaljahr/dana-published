DANA JOURNALISM — CMS / STUDIO QA
================================

Reader / CMS integration
- Bundled archive contains 33 unique slugs.
- Published CMS rows merge into the reader and override matching bundled slugs.
- The Studio automatically imports missing bundled stories into cms_articles after authenticated owner entry.
- Existing original publication dates are preserved during bootstrap.
- New published stories receive the Saudi local publication date.
- New stories with no uploaded image use a section fallback cover.

Private Studio
- studio.html includes noindex,nofollow,noarchive and has no reader-side navigation link.
- Owner email is restricted in database/login flow to the configured owner account.
- Passwordless Supabase authentication.
- Image uploads use the public article-images bucket, with write policies restricted to authenticated admin.
- Draft / publish / edit / delete supported.

Analytics
- page_view, article_view, scroll_50, scroll_90, article_leave, session_start, search, share, save.
- Dashboard ranges: 7 / 30 / 90 days.
- Page views, visitors, sessions, article reads, completion, average read time, pages/session, approximate bounce rate, shares, saves, searches, devices, referrers, top content, daily chart.

Security notes
- RLS is enabled for admin_users, cms_articles and site_events.
- Anonymous/public readers can read only published CMS content.
- CMS writes and analytics reads require authenticated admin.
- Supabase currently reports the optional leaked-password-protection warning; this Studio uses passwordless email links rather than account passwords.
