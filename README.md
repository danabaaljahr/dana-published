# دانه بالجهر — Editorial Portfolio

موقع صحفي شخصي ثابت وجاهز للرفع مباشرة على GitHub Pages. لا يحتاج إلى npm أو build أو قاعدة بيانات.

## المحتوى
- 33 مادة صحفية أصلية كاملة من `articles.js`
- 7 أخبار
- 11 تقريرًا
- 14 مقالًا
- تجربة تدريبية واحدة
- الإحصاءات المنظمة داخل التقارير
- 11 نقطة benefits في «بين الدراسة والممارسة»

## تجربة الاستخدام
- واجهة عربية / English (تبقى المواد الأصلية بالعربية كما هي)
- Light / Dark بتصميم أبيض وأسود
- شريط ثابت سريع لاختيار ما تريد رؤيته
- بحث من بداية كلمات العنوان فقط، مع دعم لوحة المفاتيح
- قسم أعمال تفاعلي يتغير فور اختيار خبر/تقرير/مقال/تجربة
- سكة أفقية للأعمال المختارة تدعم السحب بالماوس
- حفظ المواد محليًا دون حساب
- قسم «أكمل القراءة» لآخر المواد المفتوحة
- «فاجئني» لاختيار مادة عشوائية من الأرشيف
- أرشيف Grid / List مع تصفية وبحث
- وضع قراءة: تكبير/تصغير الخط، تغيير عرض النص، Focus Mode، تقدم القراءة
- مشاركة المادة، السابق/التالي، ومواد ذات صلة
- انتقالات View Transitions عند دعم المتصفح، Reveal animations، Hover/Tilt، Cursor OPEN، Magnetic buttons
- احترام `prefers-reduced-motion`
- PWA / Service Worker وتخزين الواجهة والأغلفة الأساسية
- 404 مصممة خصيصًا للموقع

## الرفع على GitHub Pages
ارفع **محتويات هذا المجلد نفسها** إلى جذر المستودع، ثم من Settings → Pages اختر النشر من الفرع الرئيسي.

ملف `.nojekyll` موجود لتجنب معالجة Jekyll.


## Dana Studio — لوحة الإدارة الخاصة

- واجهة القراء: `index.html` (لا تحتوي أي رابط إلى لوحة الإدارة).
- لوحة الإدارة الخاصة: `studio.html`.
- حساب الإدارة الوحيد المسموح به: `Danahfahad.mb@gmail.com`.
- الدخول Passwordless عبر Supabase Magic Link؛ لا توجد كلمة مرور داخل ملفات GitHub.
- النشر من Studio يذهب مباشرة إلى Supabase ويظهر للقراء دون إعادة رفع الموقع.
- رفع الصورة اختياري؛ عند عدم اختيار صورة يستخدم الموقع غلافًا موحدًا تلقائيًا حسب النوع: خبر / تقرير / مقال / تجربة.
- التحليلات تبدأ بالتجميع من لحظة نشر هذه النسخة، ولا يمكنها استرجاع زيارات حدثت قبل تركيب نظام القياس.

### إعداد واحد بعد ظهور رابط GitHub Pages
بعد رفع الموقع ومعرفة الرابط النهائي، أضيفي رابط `studio.html` في Supabase: Auth → URL Configuration → Redirect URLs. مثال: `https://USERNAME.github.io/REPO/studio.html`. هذا مطلوب من Supabase لحماية روابط الدخول البريدية.
